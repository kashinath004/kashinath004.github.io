## 🚀 How to View & Deploy

### Quick Local View (Instant)
Simply double-click [`index.html`](file:///C:/Users/kashi/Downloads/New%20folder%20(10)/index.html) in your browser. No build tools or installations required.

Alternatively, start a local server:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).

### Deploying to GitHub Pages (Free, 2 Minutes)
1. Initialize a git repository:
   ```bash
   git init
   git add .
   git commit -m "feat: Kashinath B R Portfolio"
   ```
2. Create a repository on GitHub (e.g. `kashinath-portfolio`).
3. Push your repository:
   ```bash
   git remote add origin https://github.com/<your-username>/kashinath-portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub Repo Settings ➔ **Pages** ➔ Branch: `main` / `root` ➔ Click **Save**.
